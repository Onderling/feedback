# Security policy

## Reporting a vulnerability

Report vulnerabilities privately to **security@onderling.org** — please do not open public
issues for security problems. Include the affected area (channel / pod / pipeline), a
reproduction, and the impact as you understand it. You will receive an acknowledgement within
7 days; disclosure is coordinated.

This is privacy software: findings about anonymization bypasses, pseudonym linkability,
pod access control, sealing, and PII leakage into logs or prompts are explicitly in scope
and especially welcome.

## Supported versions

Pre-1.0 research preview: the latest state of `master` only.
